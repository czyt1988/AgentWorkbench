# 文档撰写规范

本目录下的文档遵循同一份撰写规范：**[docs/AGENTS.md](../AGENTS.md)**。

那份规范本身就用中文撰写（它是面向 agent 的工作约定，与仓库根目录的 `AGENTS.md` 同级性质），因此这里不重复一份副本——重复会带来两处漂移。请直接读它，要点包括：三个板块（`architecture` / `development` / `guide`）各自的读者与语气红线、中英文一一对应规则、全文档不写行号、mermaid 作图与站内链接约定，以及「改了代码要同步改哪些文档」的对照表。

写作前请确认：英文文档是源头（`docs/`），中文镜像是同一笔提交里必须一起出现的（`docs/zh/`，文件名与章节结构完全一致）。
