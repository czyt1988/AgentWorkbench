# Agent 启动器

**Agent 启动器**页面用来管理你电脑上安装的 AI 编程 agent：启动它们、查看它们是否在运行、打开它们的网页界面。每一个 agent 就是一张卡片。

## 这是什么

启动器页面是一格格卡片，每个 agent 一张。它知道怎么启动每个 agent 的本地 Web 服务，也知道怎么检测那个服务是否在线，但它并不负责安装或运行 agent 本身的逻辑——它只是把你已经装好的工具启动起来。

## 什么时候用它

- 启动一个 agent 并进入它的网页界面。
- 一眼看出当前有哪些 agent 在运行。
- 安装、更新或重新配置一个 agent。
- 添加一个不在内置列表里的新 agent。

## 看懂一张卡片

每张卡片上显示：

- **agent 的图标。** 没有自定义图标时用一个中性的占位图标。
- **卡片正中的名称。**
- **名称下方的状态文字**：**运行中**、**已停止**、**正在启动…**、**正在停止…**、**正在设置…** 或 **正在安装…**。这里也可能显示一条简短错误信息，同时卡片边框变红。
- **图标旁的小圆点。** agent 运行中时填满颜色。
- **左上角的版本标签。** 检测到已安装版本后显示（例如 `1.2.3`；读不到版本则显示**已安装**）。如果看起来没有安装，那里会显示一个下载图标——点它执行安装命令。标签和图标都依赖启动时的版本检查；在 **设置 → 启动器** 里把它关掉后，卡片两者都不显示。
- **底部的主动作按钮**：停止时是 **开启**，运行时是 **打开**。点卡片任意位置效果相同。
- **旁边的设置按钮**，打开该 agent 的编辑表单。
- **右上角的小 ×**，只在 agent 运行时出现。点它停止该 agent（见下文）。
- **控制台输出面板**，位于状态行和按钮之间，在安装、更新或初始化命令有输出时显示。可以用面板自己的 × 收起，再从右键菜单重新打开。

## 启动与停止

**启动一个 agent：** 点它的卡片，或点 **开启** 按钮。卡片会变成 **正在启动…**，agent 的 Web 服务在后台启动，不会弹出可见的终端窗口。当应用能访问到 agent 的 Web 地址后，卡片显示 **运行中**，按钮变成 **打开**。

**打开它的网页界面：** 点 **打开**（或点卡片）。见[内嵌网页界面](网页界面.md)。

**停止一个 agent** 有两种不同的操作，它们并不等价：

- **卡片上的 ×。** 只有当 agent 是*本次会话中由本应用启动的*，它才会被关闭。如果启动之后应用重启过，应用就不再知道那个进程，这时点它只会提示你一句——不会停掉任何东西。
- **右键菜单里的强制停止。** 它会找到正在服务该 agent Web 地址的程序并结束它，无论那个程序是谁启动的。由于它可能结束你在别处启动的程序，会先让你确认。

如果两者都不合适，最稳妥的办法始终是用 agent 自己的命令停止它（比如关掉它自己的终端窗口）。

## 右键菜单

在任意卡片上点右键：

| 菜单项 | 作用 |
|---|---|
| **开启** / **关闭** | 启动 agent；或停止本次会话中由本应用启动的那个。 |
| **强制停止** | 结束正在服务该 agent Web 地址的程序，会让你确认。仅在 agent 运行时可用。 |
| **在浏览器打开** | 用你平时的浏览器打开该 agent 的 Web 地址，而不是应用内标签页。仅在运行时可用。 |
| **安装** / **更新** | 执行 agent 的安装或更新命令。按 agent 是否已安装，两者只显示一个。agent 运行时不可用。 |
| **显示输出** | 重新打开控制台面板，显示上次捕获的输出。 |
| **设置** | 打开该 agent 的编辑表单。 |
| **打开配置文件夹** | 用文件管理器打开该 agent 自己的配置文件夹。 |
| **重新初始化** | 忘掉「一次性初始化命令已经跑过」的记录，下次启动时再跑一次。仅当该 agent 配置了初始化命令时可用。 |

## 添加一个 agent

有两种方式。

### 在页面上添加

点页头的 **添加启动器**。会打开一个表单，包含这些字段：

- **名称**（必填）——卡片上显示的标题。
- **启动命令**（必填）——启动该 agent 的命令行，例如 `kimi web --port 58628`。它在后台运行，没有可见窗口。
- **Web 地址**（必填）——agent 网页界面的地址，例如 `http://127.0.0.1:4096`。端口要和命令里的一致。
- **ID**——内部的唯一名称。留空会根据名称自动生成。创建后不可修改。
- **配置目录**——该 agent 自己的配置文件夹，供 **打开配置文件夹** 使用。
- **图标**——见下面「图标与颜色」。
- **主题色** 与 **卡片背景色**——见下面「图标与颜色」。
- **安装命令**、**更新命令**、**版本命令**——可选命令，供 **安装**、**更新** 和版本检测功能使用。
- **首次运行准备命令**（在 **高级** 小节）——agent 首次启动前执行的一次性命令，例如创建令牌文件。
- **令牌文件**（在 **高级** 小节）——指向一个文件，其内容会在启动时交给 agent，并在打开网页时追加到 Web 地址上。除非该 agent 需要，否则留空。

点 **保存**，卡片立即出现。

### 手动编辑配置文件

熟悉配置的用户也可以直接编辑配置文件来添加 agent，不过对大多数人来说上面的表单更省事。这个文件是数据文件夹里的 `agents.json`（文件夹位置见[用户指南](index.md)）。它就是一个纯文本配置文件；如果你不习惯编辑它，请改用表单。

每个 agent 是 `agents` 列表里的一段。最小可用的一条包含四个字段：

```json
{
  "id": "my-agent",
  "name": "My Agent",
  "command": "my-agent serve --port 3000",
  "webUrl": "http://127.0.0.1:3000"
}
```

- `id`——agent 的短唯一名，使用字母、数字、`-` 或 `_`，不能和任何内置 agent 相同。
- `name`——卡片上显示的名称。
- `command`——启动该 agent 的命令。
- `webUrl`——它的网页界面地址，包含端口。

保存文件并重启应用即可看到新卡片。使用与内置 agent 相同的 `id` 不会生效——内置 agent 每次启动都会按应用自带的默认定义重新生成。

## 修改与删除 agent

打开 **设置 → 启动器**。你会看到所有 agent 的列表，每行有：

- **编辑**——打开与 **添加启动器** 相同的表单，内容已填好。窗口里也会提示修改是立即生效还是下次启动生效。
- **删除**——确认后移除该 agent。如果 agent 正在运行，删除它并不会停止它；请用它的自己的命令停止。如果删掉的是内置 agent，之后还能找回。

要恢复内置 agent，点启动器页面上的 **恢复默认**，或 **设置 → 高级** 里的 **恢复默认启动器**。这会把你删掉的内置 agent 加回来，并把你对内置 agent 的修改还原。

!!! warning "修改内置 agent 只在本次运行内有效"
    你对**内置** agent 的修改（比如换个端口）只在应用本次运行期间生效。下次启动时，它会按应用自带的定义还原。想让修改长期生效，请改成添加一个**你自己的** agent，或者请构建这个应用的人去改内置默认值。你自己添加的 agent 不受这个重置影响。

## 图标与颜色

**图标** 字段接受三类值：

- **内置图标**，从字段下方那排小图标里选。点一下即可填入。
- **你电脑上的文件**——任意 `.svg` 或 `.png` 文件。可以用 `~` 表示主目录，用 `%变量名%` 表示环境变量，例如 `%USERPROFILE%/icons/my-agent.svg`。
- **以 `http://` 或 `https://` 开头的网址。**

**图标** 留空则使用默认占位图标。

**主题色** 是 agent 的强调色，格式为 `#RRGGBB`（六位十六进制，例如 `#89B4FA`）。agent 运行时卡片会带上这个色调。**留空会从当前主题的调色板自动分配一个颜色。**

**卡片背景色** 设置 agent 未运行时卡片的背景。留空则使用正常的表面背景色。

## 安装与更新

如果某个 agent 还没安装，启动器可以替你运行安装命令：

- **安装** 动作（下载图标，或右键菜单里的 **安装**）会执行你在 **安装命令** 里配置的命令。
- **更新** 动作（版本号旁边的 ↻ 图标，或菜单里的 **更新**）会执行 **更新命令**。

两者都要求填好了对应的安装/更新命令，且 agent 必须先停止——如果它正在运行，卡片会提示你先关闭再安装。命令的输出会实时显示在卡片的控制台面板里。命令失败时，面板会保留几秒让你看清错误，完整信息还会额外弹窗显示。

## 一次性初始化

有些 agent 在第一次启动前需要一小步准备工作，比如生成登录令牌。如果配置了 **首次运行准备命令**，它会在 agent 首次启动前自动执行。执行成功后应用会记住，不再重复运行。

如果想再跑一次——例如令牌丢了——用卡片右键菜单里的 **重新初始化**。

## 「运行中」是怎么判断的

应用不靠监视进程来判断 agent 是否在运行。它每隔几秒访问一次 agent 的 Web 地址，**只要有任何响应**就算「运行中」；连接被拒绝或超时则算「已停止」。

由此带来一个结果：一个地址能连上、但页面本身打不开的 agent，仍然会被标成 **运行中**。如果卡片显示 **运行中** 但页面打不开，见[出问题了怎么办](问题排查.md)。

## 小技巧

- 卡片显示 **打开** 时，直接点卡片——这是进入网页界面最快的方式。
- 给每个 agent 配一个不同的颜色，一眼就能区分卡片。
- 用 **打开配置文件夹** 去找某个 agent 自己的设置和日志。
- 用启动器页面上的搜索框按名称、命令或地址过滤，用 **全部** / **运行中** / **未安装** 按钮缩小范围。

## 出问题了怎么办

**卡片闪红并弹出「启动失败」提示。** agent 的命令没能启动起来——通常是工具没安装，或者装了但不在系统的命令路径里。先试 **安装** 动作；如果明明装好了，就在终端里手动跑一遍 agent 自己的命令看报什么错。卡片控制台面板和弹窗里都会给出原因。

**卡片显示运行中，但页面打不开。** 地址有响应就够了，检查只看这一点。可能页面本身还在启动（等几秒即可），可能端口被别的程序占了，也可能地址填错了。见[出问题了怎么办](问题排查.md)。

**内置 agent 总是忘记我的修改。** 这是预期行为——见上面的警告。请改成添加你自己的 agent。

**安装或更新好像没有任何动静。** 打开卡片的控制台面板：命令的输出就在那里。常见原因是命令依赖你没装的工具（比如 Node.js）——看看状态栏的徽标。
