# Markdown 工作台

Markdown 工作台是**一个地方干两件事**：从容地写提示词，以及阅读、整理 Markdown 文件——可以同时开好几份，各占一个标签页。**这里不会发送任何内容**——按回车只会换行；文字写好后由你复制、自己粘贴进 agent。

在侧栏的 **Agent Tools** 分组下找到 **提示词编辑** 这一行。它是 Agent Tools 家族里的一个高级功能，就住在应用主窗口里——不是一扇独立窗口：它填满侧栏与状态栏之间的工作区。

## 打开工作台

- **从侧栏。** 点 **Agent Tools** 下的 **提示词编辑**。工作台填满工作区；第一次进来要花一点时间就位，之后再切回来都是即时的。
- **从一个文件。** 在文件树里**对 `.md` 或 `.markdown` 文件点右键**，选择 **预览 Markdown**。工作台打开时把那份文档开成一个标签页。
- **双击打开。** 在设置里关联了 Markdown 文件之后（见[设置](设置.md)），在文件管理器里双击 `.md` 文件就在这里打开它。应用已经在跑时，文件开成新标签页并把应用提到最前；没在跑时先启动应用再显示它。**启动的是完整应用**——带侧栏的整个窗口——不是秒开的轻量查看器，请给它平常那点启动时间。

**为什么没有 预览 Markdown 这一项？** 两种可能：这个文件按后缀不是 Markdown 文件；或者本构建根本不具备预览能力——预览需要内嵌了浏览器引擎的那版本。没有能力时这一项压根不出现，所以不存在「点了才发现不行」。

## 两种形态

工作台按当前在做什么呈现两种形态：

- **完整形态**——写提示词的时候。左侧工作区文件树展开着，顶上是一整条功能区，中间是你的草稿。文件树下方还挂着**模板库**与**收藏夹**两段。
- **紧凑形态**——读文档的时候。文件树收成一条细边，功能区折叠成一行标签名，文档占满工作区。这是阅读的形态；打开大纲时，右栏里会出现大纲段。

工作台活着期间，两种形态各自记住自己的设置——在紧凑形态里收起了什么，完整形态照样按你上次离开的样子回来。完整形态还会跨次记住功能区的偏好（折叠与否、样式行数、上次的标签页、主题跟随）。什么都不锁死：功能区 **视图** 页里的 **完整工具** 开关在两种形态之间切换，其余任何东西也随时可以展开收起。

切到别的页面再切回来，工作台原样等着你——文字、撤销历史、滚动位置、分屏比例都和离开时一模一样。它在第一次进入时创建，一直活到应用关闭。

## 标签页：同时看几份文档

中间区上方那条带子上，每份打开的文档**和每条草稿**各占一个标签页；有**未保存改动**的 tab 上有一个小圆点。点标签页切到它；点它上面的 × 关掉它——**关标签页关的只是视图，永远不删内容**：文档还在磁盘上、草稿还在应用的存储里，再打开哪一个都只需点一下。

- 一次最多打开八份文档。开第九份时会提示先关一个标签页——绝不会在你背后悄悄关掉任何东西。
- 同一个文件开两次不会出现第二个标签页；它会把已经在的那个激活，你正在做的编辑也跟着回来。
- 每个标签页记住自己的**预览 / 分栏 / 源码**设置；切标签页就切到那个 tab 的视图。
- 草稿标签页与文档标签页混排在一起；见[草稿：多条同时写](#草稿多条同时写)一节。

## 功能区

功能区是工作台顶部那条按钮带。它的标签页是：

- **开始**——日常动作：**复制提示词**（提示词就是这样离开工作台的——标题行的小条上还有第二个 **复制**）、剪贴板动作 **粘贴**、**剪切** 与 **复制文字**，**撤销** 与 **重做**，格式按钮 **加粗**、**斜体**、**删除线**、**代码段**、**链接**、**标题**、**要点列表**、**编号列表**、**任务清单**、**引用**、**分隔线**、**围栏代码块** 与 **表格**（见[格式工具](#格式工具)一节），以及草稿动作 **新建草稿**、**从文档新建**、**重命名**、**复制草稿** 与 **保存版本**（见[草稿：多条同时写](#草稿多条同时写)一节）。这一页还有 **查找**（见[查找与替换](#查找与替换)）、**保存**（文档标签页激活期间）与 **清空**（写提示词时）。
- **提示词工具**——只在写提示词的时候出现（切到文档时它会消失）：**插入模板** 打开模板库，**存为模板** 与 **存入收藏夹** 把你写好的东西保存下来，**体检提示词** 给草稿提建议（见[提示词体检](#提示词体检)一节）。见后面两节。
- **视图**——看什么、怎么看：**预览 / 分栏 / 源码** 切换与大纲开关、**完整工具**（在两种形态之间切换）、**折叠**（把整条功能带收起来）、**样式**（一行、两行或三行按钮），以及 **跟随主题**（功能带的颜色是否跟着应用主题走）。

- **折叠。** 功能区可以折叠成一行标签名，给文档让出空间——点那一行即可再展开。紧凑形态默认就是折叠的。
- **配色。** 功能区的颜色自动跟随应用的外观主题；**跟随主题** 可以把它关掉，关掉后功能带保留自己的配色。
- 个别自行构建的版本会用一条简单的工具栏代替功能区，动作是一样的。

## 写一条提示词

1. 从文件树顶部的 **工作区** 菜单里选一个文件夹，或点它旁边的**文件夹按钮**（悬停提示为 **选择工作区文件夹**）添加一个。
2. 在中间写提示词。按回车只会插入一个换行——不会发送任何东西。底部那行会替你数着字符数与行数，还会估算提示词的 token 体量（是估算——见[token 估算](#token-估算)一节）。
3. 从文件树里把文件带进来：**把文件行拖进编辑区**，或**双击文件行**。这会在光标处插入对该文件的引用，写成 `` `./相对路径` `` 的形式。
4. 写完点 **开始** 标签页里的 **复制提示词**。提示词进入剪贴板并给出确认提示；把它粘贴到 agent 里即可。

**草稿们会自动保存。** 关掉应用再打开，文字都还在。

编辑区里常用的文本快捷键都可用：`Ctrl+Z` 撤销、`Ctrl+Y` 重做、`Ctrl+X` / `Ctrl+C` / `Ctrl+V` 剪切、复制、粘贴（见[用户指南](index.md)）。在编辑区里点右键，会出现一个菜单，装着同一批格式按钮与剪贴板动作。

草稿也有渲染视图，和文档一样——用上方那排**预览 / 分栏 / 源码**按钮切换。写长提示词时**分栏**最顺手：左边是文字，右边是渲染出来的样子。

## 草稿：多条同时写

不必只养一条写到一半的提示词。**新建草稿**（功能区的**开始**标签页，或工具栏的加号按钮）开一条新草稿、占一个新 tab；原来那条待在自己的 tab 里，文字原样。点各条草稿的 tab 切换——每条草稿有自己的撤销历史，撤销永远不会串到之前写的那条里去。

- **重命名**草稿在**开始**标签页；标题会显示在 tab 上。
- **复制草稿**拷贝当前草稿并切到副本——「留个版本」的动作。
- **删除**会先确认，且**不可撤销**：草稿正文、它的版本历史和崩溃恢复副本一起走。
- **关掉草稿的 tab 不是删除它**：草稿存在应用自己的存储里，再打开就回来。

**从文档来：** **从文档新建**（**开始**标签页，开着文档 tab 时可用）把文档的文本变成一条新草稿并切到提示词形态。它是单向的——草稿归你随便改，保存它永远不会写回原文件。

## 版本与恢复

你写的时候，应用会悄悄给每条草稿留版本——复制它、清空它、替换它、或切去别的草稿时都会存一版；**保存版本**（**开始**标签页）手动标记一版。

右栏的**历史**段列出当前草稿的版本，新的在前，并注明每一版是因什么存的。**点一版即可回滚。**确认对话框会说明你当前的文本先存成一版——回滚永远不丢东西。

应用意外关闭时，下次启动会问一次：把那次会话的草稿文本**恢复**成一条新草稿，还是**丢弃**。

## 模板：从骨架写起

左栏的**模板库**段（在文件树下面）是一排现成的提示词骨架——报 bug、加功能、补测试、代码审查等等。十条是内置的，一直都在；你自己存的模板也出现在同一个列表里。

- **搜索**随着输入实时收窄列表——标题、描述、标签和模板正文都在匹配范围内。
- **点一下模板**就把它插进草稿的光标处。插入永远不会覆盖你写的东西：骨架落在光标处；如果当时选中了文字，它会被填进模板的 `{{selection}}` 占位符里。
- **占位符。**模板正文里有一些填空位，比如 `{{symptom}}` 或 `{{symptom:具体什么表现不对}}`。模板里有占位符时，会弹出一张小表单：每个占位符一行，有默认值的已经预填好。`Tab` 在字段之间跳，`Enter` 插入，`Esc` 取消。**留空的字段就是跳过**——占位符会以 `{{symptom}}` 的原样留在正文里，这样你还能找到它，而不是提示词揣着没填完的空悄悄发出去。同一个占位符出现两次时，填一次、处处替换。
- 有两个占位符是自动填的、不会问你：当前的**工作区**路径和今天的**日期**。

**存自己的模板：**提示词写到满意的样子后，用**存为模板**（功能区的**提示词工具**标签页，或工具栏）。一张小表单——标题（预填草稿首行）、分类、一句描述——存完马上出现在模板库里。你存的模板是应用数据文件夹里的普通文件，一模板一文件：可以用任何文本编辑器改，可以备份，也可以直接拷给同事。想让某条内置模板按你的样子来，把你的文件存成同名即可覆盖。

## 收藏夹：写好的成品

模板是带洞要填的骨架；**收藏夹**是你想原样再用的完整提示词。**收藏夹**段在模板库段下面（默认收起——点开即可）。

- **存收藏**用**存入收藏夹**（**提示词工具**标签页，或工具栏）：整份草稿变成一条收藏，标题取首行。确认提示会告诉你存好了。
- **点一下收藏**，把全文插进草稿的光标处。
- 悬停收藏行会露出**复制**（直接进剪贴板，不插入）与**删除**。
- 收藏存在应用自己的设置存储里，上限五十条；同一段文字再存一次只是刷新它，不会占第二个位置。

**哪个放哪？**如果每次用都要把占位符删掉，那它其实是一条收藏，不是模板；如果每次都要往空里填字，那它是模板。两个段把它们分开，点下去做的就是对的事。

## 格式工具

功能区的 **开始** 标签页装着格式按钮：**加粗**、**斜体**、**删除线** 与 **代码段**（这四个会亮起来，表示光标处现在就是这种格式——点一下切换）、**链接**、**标题**（菜单里有一、二、三级和取消）、**要点列表**、**编号列表**、**任务清单**、**引用**、**分隔线**、**围栏代码块**（菜单里是常见语言）与 **表格**。

- 每个动作都是**一步撤销**：做完立刻按 `Ctrl+Z`，整个改动一起退回。
- 开关是诚实的：对全部已编号的行再点 **编号列表** 是把编号去掉；标题是换级而不是把 `###` 叠在 `##` 上。
- 文档标签页里，只要文件可编辑，同一批按钮在源码区照样能用——格式化不是提示词专属。

工作台新增的键盘快捷键只有 `Ctrl+F`（查找——见下一节）与 `Esc`（收起查找条）。其余都是按钮。

## 查找与替换

**写提示词时**，按 `Ctrl+F` 或点 **开始** 标签页的 **查找**：编辑区上方滑出一条查找条。输入要找的文字；**下一处** 跳到一个命中并选中（搜到底回头再搜时会提示一句）；**替换** 换掉当前命中并跳到下一处；**全部** 先问一次、然后换掉所有命中，并告诉你换了几处。

- **Aa** 让搜索区分大小写；**Whole** 只匹配整个词。这两个设置跨会话保留。
- 一次撤销能退回整轮 **全部** 替换。
- `Esc` 收起查找条。
- **文档标签页里**，`Ctrl+F` 找的是渲染后的页面（见[在文档里查找文字](#在文档里查找文字)一节）。两个搜索不一样：提示词的查草稿原文，文档的查渲染页——它们回答的问题不同。

## 提示词体检

右栏的 **体检** 段（写提示词时在场）审一遍草稿，给出一列建议——**不评分**。点 **体检**（或 **提示词工具** 标签页的 **体检提示词**）运行。

- 每条命中一行，前面一个色点：灰色是提示、黄色是提醒、红色是警告。
- **点一条命中**，编辑器跳到它说的位置并选中相关文字（针对整条提示词的发现——比如缺验收标准——没有可跳的位置）。
- **某类建议看烦了？**命中行上的 × 把那条规则永久关掉——列表立刻重跑、那一类建议当场消失。（还没有把它们开回来的设置界面：开关清单存在应用数据文件夹的 `tools.json` 文件里的 `checks` 段。）
- 它找这些：模糊措辞、通篇只问不指令、没有验收标准、该写成 `./这样/的` 的 Windows 风格路径、没点名技术栈或文件、上下文预算风险、长提示词没有分段、`{{占位符}}` 没填、行尾空白，以及会弄坏命令行的智能引号。

## token 估算

底部状态行对草稿显示「~1,240 tokens (estimated)」（打开的文档也有同款数字）。**这是个估算**——粗略衡量 agent 将读到的上下文量，不承诺与任何模型的实际分词一致。当量级看：几百是小、上万是很大。

- 颜色跟着体量走：小的时候中性色，到上下文窗口的四分之一转警示色，超过五分之三转红色。
- 估算对着的大小基准默认是 32000 token。可以在应用的 `tools.json` 文件里改（`editor` 段的 `contextWindowTokens`）——还没有设置界面。
- 悬停草稿上那个数字，会说明它是对着多大的上下文窗口估的。

**清空整份草稿**（**开始** 标签页的 **清空**，仅提示词形态）永远先问一次；确认清掉之后 `Ctrl+Z` 也还能把文字找回来。

## 三种视图

中间区上方那排按钮切换显示什么——对草稿、对激活的文档标签页都一样：

- **预览**——只显示渲染结果。
- **分栏**——左边是纯文本，右边是渲染结果。
- **源码**——只有纯文本，什么都不渲染。

文件写不回去的时候，**分栏** 与 **源码** 是灰的；只有 **预览** 可用，底部的状态行会说明原因。没有预览能力的构建上这些按钮不出现，文字就留在编辑器里。

## 阅读文档

中间区上方那条带装着阅读控件：**预览 / 分栏 / 源码** 三个按钮、**大纲** 按钮、**搜索** 按钮、**文字大小** 与 **宽度** 选择，以及 **更多操作** 菜单。

- **大纲。** 右栏的大纲段列出当前打开内容（草稿也算）的各级标题，点一条就跳过去。没有标题的文档显示 **没有标题**。
- **文字大小。** 选正文字号：**主题字号** 跟随当前的外观主题，也可以直接选 12 px 到 24 px 之间的固定值。
- **宽度。** 选正文栏宽：**默认栏宽**、某个固定宽度，或 **满栏** 用掉整个工作区。
- **状态行。** 显示文件路径、文件字节数、渲染组件的版本号、文件正文的 token 估算；有没存盘的改动时显示 **有未保存的改动**；文件不能编辑时显示原因。

## 在文档里查找文字

按 `Ctrl+F`，或点窄带上的搜索按钮。输入文字后用 **下一处** 和 **上一处** 逐个跳转，旁边的标签告诉你现在在第几处（**第 3 处，共 17 处**）。打开 **区分大小写**（Aa）就是大小写敏感搜索。`Esc` 收起搜索条。

有两件事它做不到，两件事都是因为「这个工作台靠什么把长文件渲染得快」：

- 它只统计**已经排版出来**的部分。非常长的文档刚打开就搜，命中数可能比过一会儿再搜要少——等整篇渲染完再搜一次就齐了。
- 它找不到被格式打断的文字。搜「调查」匹配不到 `强**调查**研` 里的这一段，因为加粗符号把这个词切成了几块。

## 编辑与保存

在 **分栏** 或 **源码** 里打字。应用不会不打招呼就丢掉你的劳动：

- `Ctrl+S` 写盘。会有确认提示，**有未保存的改动** 也随之消失。
- 带着未保存的改动退出应用，会问一句，三个选择：**保存并退出**、**放弃更改**、**取消**。改过的文档不止一份时，对话框会数出总数，**全部保存并退出** 把每一份都写盘——不只是你正看着的那个标签页。
- 你有未保存改动期间，别的程序改了这个文件，会弹出一个对话框：**从磁盘重新加载** 取外面那份、丢掉你这份；**保留我的改动** 留下你这份，并且不再为这一次外部改动反复追问。
- `F5` 从磁盘重读这个文件。如果你有未保存的改动，它会先问你，所以 `F5` 不会悄悄把你的编辑扔掉。

**保存会保留文件原本的样子。** 文件用的是 Windows 换行，或者开头带字节顺序记号，存盘之后还是如此。应用不会把你的文件「整理」成另一种形态。

文件只读有三种原因，状态行会说出是哪一种：太大、不适合在这里编辑（预览照常可用）；盘上不可写；或者文字不是合法的 UTF-8——这种存回去会造成永久损坏，所以直接拒绝编辑。特别大的文件（几十兆）根本不会打开，而不是打开之后卡在那里。

## 回到上次开着的那些

切到别的页面再切回来，一切照旧：同样的标签页、同样的激活位，连没保存的编辑都还在。只有关标签页或重启应用才会真正清掉什么。

**重启也能把标签页找回来。** 应用记住开过哪些文档与草稿、激活的是哪个、每个标签页的视图设置；重启后第一次进入工作台就把它们恢复出来。期间被移动或删除的文档、或已删除的草稿直接跳过——其余照常回来。记住的形态（完整或紧凑、各段折叠与否）也一起回来。

**应用启动时不会自己打开工作台**——启动保持又快又安静。如果你希望应用一启动工作台（连同上次的标签页）就已经开着，去[设置 → 启动器](设置.md)打开 **启动时打开 Markdown 工作台**。

## 复制、在别处打开、导出

这些都在文档上方窄带右端的 **更多操作** 里：

- **复制所选内容** 复制你选中的那段渲染后的文字。先在预览区选中，否则应用会提示你未选中内容。
- **复制 Markdown 源码** 复制原始的 Markdown。
- **在浏览器打开** 把渲染结果写出一份副本，并用系统浏览器打开它。副本落在应用自己的数据目录里、按文档名命名，所以对同一个文件再用一次会覆盖那份副本。
- **在文档旁导出 HTML** 在 Markdown 文件旁边写出一份自包含的 HTML。
- **导出 HTML 到指定文件夹…** 由你挑目录。

两种导出完成后都会给一条说明文件位置的消息，并带你看到它落在哪儿。两者都会先把整篇渲染完再落盘——图表很多的文档会稍等片刻才出现文件。

关于导出有一点要注意：导出件引用图片用的是**相对文档的路径**，所以图片只有在 HTML 与它们放在一起时才显示得出来。导出到别的目录是你的选择，但图片不会跟着走。

## 哪些内容会渲染，哪些不会

公式、图表、表格、任务清单与代码高亮都可用。具体说：

- 用 `$$ … $$`、`\[ … \]` 以及行内写法写的公式会排成真正的数学式子。写错的公式显示成红色，而不是被藏起来。
- 语言标记是 `mermaid` 的代码块会变成图表。图表是滚到附近才画，不是一次全画——图表非常多的文档会让你点一下某张图再画它。
- GitHub 风格的提示块（`> [!NOTE]` 以及另外四个）画成带语义色的告警条。
- **文档里内嵌的 HTML 不渲染。** 直接写在 Markdown 里的标签会显示成正文文本。这是刻意的安全选择：这里看的是不是你写的文件，而文档里的 HTML 本来能在应用里执行代码。

## 使用文件树

- **点文件夹**可以展开或收起。有内容的文件夹带一个箭头。
- **双击文件**会把对该文件的引用插入草稿。
- **把文件行拖进编辑区**会在落点插入引用。
- **在文件行上点右键**，有 **复制相对路径** 或 **复制绝对路径**。若这是一个 Markdown 文件，菜单里还会多一条 **预览 Markdown**。这条只在这个构建具备预览能力、且文件按后缀属于 Markdown 时才会出现。
- 文件变化时文件树会自动刷新；工作区菜单旁边的刷新按钮可以手动刷新。

## 管理工作区文件夹

- 工作区菜单旁边的**文件夹按钮**（悬停提示为 **选择工作区文件夹**）会打开文件夹选择器，可以选电脑上的任意文件夹。
- **工作区** 菜单列出你的文件夹，最近使用的排在最前。选一个即可切换。
- 该菜单里每一项都有一个 ×，可以把它从列表中移除。
- 应用最多记住二十个文件夹。添加第二十一个时，会挤掉最久没用过的那个。

## 小技巧

- 把你正在工作的文件夹加进来，再随手放几个常用的——切换只要点一下。
- 把文件拖进一句话中间，往往比手写路径更快。
- 在这里写好一段可复用的指令，复制一次，粘到多个 agent 里。
- 一份合格的 bug 报告大半是结构——从报 bug 模板起步、填空就好；调教出自己的样子后，存成自己的模板。
- 一直在重打的提示词应该进**收藏夹**；一直在重打的提示词*结构*应该进**模板库**。
- 提示词写长了？复制之前先跑一遍 **体检提示词**——命中清单通常会点名缺的那一样东西。
- 查找条的 **Aa** 与 **Whole** 设置会记住：按自己的大小写习惯设一次就不用再管。

## 出问题了怎么办

**列表里少了一个文件夹。** 文件夹上限是二十个，添加新的时候会挤掉最久没用过的那个。还需要就再加一次。

**文件树是空的。** 确认选中的文件夹仍然存在、而且不是空的。这种情况下工作台会显示 **工作区文件夹为空或不可用。** 用刷新按钮，或换一个文件夹。

**文件拖不进编辑区。** 确认你拖的是文件树里的行，而不是别处的文字。从文件树拖进编辑区会插入引用；在编辑区内拖文字则是移动这段文字。

**点复制没反应。** 如果编辑区是空的，应用会提示你没有可复制的内容。

**预览区什么都没有。** 先看状态行，文件读不了时它会写明原因。空文件在预览区显示 **文档为空**，在编辑区显示 **没有可编辑的内容**。

**图表是空的或报错。** 解析不过的图表会显示 **图表无法绘制**；在 **源码** 里改好文字，这一块会自己更新。图表很多的文档里，占位上写着 **点击渲染此图表**，不点就一直空着——这是工作台拒绝把几十张你不会去看的图全画出来。

**有内容没渲染成功。** 文档中某一块失败时会给出提示，其余部分照常显示——不会安静地留半页空白给你。

**打不开第九份文档。** 标签页条最多装八份文档。看完哪个标签页就关掉它——文件本身永远不会被动到——再开下一份。同一个文件开两次不需要第二个标签页：它会把已经在的那个提到前面。

**重启后有个标签页空了或没了。** 记住的标签页是从文件重新打开的；被移动或删除的文件直接跳过（其余照常回来），读不了的文件会在状态行里说明原因。

**双击 `.md` 文件打开的是别的程序。** 关联只是把本应用放进「打开方式」列表——默认应用在 Windows 设置里选。右键文件、选 **打开方式**、在这里挑本应用（或把它设为默认）。

**提示词工具标签页不见了。** 它只在写提示词的时候出现。用 **视图** 页里的 **完整工具** 切回提示词，它就回来了。

**插进去的模板里还留着 `{{占位符}}`。** 这就是表单里留空的含义——被跳过的字段会特意留在明面上。在草稿里把它填上，或重新插入一次模板、这次把这个字段填了。

**我存的模板不在列表里。** 搜索后列表最多显示三十行；把搜索词收窄，或去模板文件夹看一眼（那些是纯文本文件——头部写坏的文件也能加载，标题回落为文件名）。

**正文好好的，只有公式和图表区域一直是空的。** 这通常意味着页面没能取到它自己的资源。重新打开该文件；如果一直如此，说明本构建的预览组件没有正确安装，提示里会说明原因。

**我把某条体检关了，想开回来。** 关掉的清单存在应用的 `tools.json` 文件里（`checks` 段的 `disabled` 列表）：把那条规则的名字从列表里删掉，建议就回来了。还没有开回来的设置界面。

**`Ctrl+F` 在提示词里什么都没搜到，文字明明就在那儿。** 提示词的查找条搜的是草稿原文；文档标签页的 `Ctrl+F` 搜的是渲染后的页面。确认开的是你要的那一个——再看看 **Aa** 和 **Whole** 两个开关。

**token 估算看着不对。** 它就是估算——见[token 估算](#token-估算)一节。如果量级总是对你的用法偏高或偏低，`tools.json` 里可以改它对着的大小基准（`editor` 段的 `contextWindowTokens`）。

想了解它内部是怎么实现的？见 [Markdown 工作台](../development/Markdown工作台.md)。
