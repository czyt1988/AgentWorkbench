# 用户指南

AgentWorkbench 是你电脑上 AI 编程 agent 的统一启动台和浏览器工作区。你不用再记住每个工具各自的启动命令、端口和配置目录——打开这一个窗口，就能看到本机安装的 agent 列表，一键启动它们，并在标签页里打开它们的网页界面。

可以把它理解成「遥控器 + 浏览器」的组合：它本身不实现任何 agent，只是把你已经装好的 agent 启动起来，并把它们的网页并排放在一起。

## 它解决什么问题

- **每个 agent 启动命令不同。** 它们各自会起一个本地 Web 服务，命令和默认端口都不一样。你只需要点 **开启**。
- **每个 agent 配置目录不同。** 卡片可以直接帮你打开那个 agent 自己的配置文件夹。
- **浏览器标签越开越多。** 每个 agent 的网页界面都在应用内的标签页里打开，不用在浏览器窗口里到处找。
- **提示词还没写完就发出去了。** 内置的提示词编辑器给你一张草稿纸，在里面按回车只会换行。

## 安装与启动

本项目目前以自行构建的源码或便携包形式分发。构建与打包方式见[构建文档](../development/index.md)。本指南从应用窗口已经打开的那一刻讲起。

> 应用会自动跟随系统语言。系统语言是中文时，界面就是中文。

## 界面导览

窗口分三部分。

**左侧栏。** 应用的所有页面都在这里。

- **Agent 启动器**——本机 agent 的卡片：启动、停止、安装与配置。
- **Agent Web UI**——在应用内显示 agent 网页界面的标签页。
- **Skills**——本机找到的「技能说明文件」的可搜索列表，附带文件位置。
- **Agent 工具**——提示词草稿纸，右侧配一个文件树。
- **设置**——以图标形式固定在侧栏最底部。主题、启动器、环境检测、skill 目录、浏览器选项、插件与重置操作都在这里。

侧栏可以折叠成一条窄窄的图标条，给工作区让出更多空间。

**右侧工作区。** 显示你在侧栏选中的那个页面。多数页面有自己的页头，上面是页面标题和属于该页面的操作按钮。

**底部状态栏。** 显示当前运行中的 agent 数量，以及在本机检测到的 Python 和 Node.js 运行环境徽标。徽标上出现红叉，表示没有找到对应的运行环境。

你上次停留的页面、窗口大小和侧栏状态都会被记住，下次打开时恢复。

## 快捷键

以下快捷键在整个窗口内都可用：

| 快捷键 | 作用 |
|---|---|
| `Ctrl+1` … `Ctrl+9` | 跳到按侧栏顺序排列的第 1、2……个页面 |
| `Ctrl+B` | 折叠或展开侧栏 |
| `Ctrl+,` | 打开**设置** |

以下快捷键在 **Agent Web UI** 页面打开时可用：

| 快捷键 | 作用 |
|---|---|
| `Ctrl+W` | 关闭当前标签 |
| `F5` | 重新加载当前标签 |
| `Ctrl+Tab` / `Ctrl+Shift+Tab` | 切到下一个 / 上一个标签 |
| `Ctrl+=` 或 `Ctrl++` | 放大 |
| `Ctrl+-` | 缩小 |
| `Ctrl+0` | 重置缩放比例 |
| `F12` | 打开开发者工具（仅调试版本） |
| `Esc` | 退出全屏 |

在 **Agent 工具** 的提示词编辑区里，常用的文本快捷键都可用：`Ctrl+Z` 撤销、`Ctrl+Y` 重做、`Ctrl+X` / `Ctrl+C` / `Ctrl+V` 剪切、复制、粘贴。

## 数据存在哪里

应用写入的所有内容都在同一个文件夹里：

| 系统 | 文件夹 |
|---|---|
| Windows | `%USERPROFILE%\.AgentWorkbench\` |
| Linux / macOS | `~/.AgentWorkbench/` |

这个文件夹里放着你的启动器列表、设置、主题、各 agent 网页界面保存的登录状态，以及日志文件。如果这台电脑上还留着旧版 *AgentLauncher* 的数据，第一次运行本版本时会把旧数据**复制**进新文件夹，旧文件夹原样保留，不会被删。

你随时可以在**设置 → 高级 → 打开数据文件夹**里打开这个文件夹。
