# 插件（用户视角）

插件让第三方给 AgentWorkbench 添加自己的页面。插件可以在侧栏里、在内置页面旁边添加一个新条目。

## 这是什么

一个插件就是放进应用数据文件夹里的一个文件夹。应用读取在那里找到的内容，如果你启用了它，就添加它提供的页面。

## 默认关闭，以及原因

**插件在你打开之前一直是关闭的。** 这是有意为之：插件运行在应用自身内部，两者之间没有任何隔离。插件能做的事，应用本身都能做。只启用你信任的来源，并且只启用你确实想要的插件。

## 怎么启用

1. 打开 **设置 → 插件**。
2. 打开 **启用插件（实验性）**。
3. 打开你想用的每个插件旁边的开关。
4. **重启 AgentWorkbench。** 插件在应用启动时加载，所以开关要等重启后才生效。

重启后，插件的页面就出现在侧栏里。

## 怎么安装别人给的插件

1. 如果应用在运行，先关掉它（也可以先把文件放好，稍后再重启）。
2. 打开你的数据文件夹（**设置 → 高级 → 打开数据文件夹**）。如果没有 `plugins` 文件夹，就新建一个。
3. 把插件的文件夹复制进去。文件夹里应该有它的说明文件和程序文件。
4. 启动应用，打开 **设置 → 插件**，把该插件打开。
5. 重启应用。新页面就出现在侧栏里。

设置页会把找到的每个插件都列出来，即使插件功能关着也一样，所以你可以在启用之前先看看有什么可用。

## 怎么停用或卸载

- **停用**：把它的开关关掉（再重启）。插件仍装在原处，只是不加载。
- **卸载**：从 `plugins` 文件夹里删掉它的文件夹。重启应用确认它已消失。

无论哪种，重启后插件的页面都会从侧栏消失。

## 信任提示

- 它可以**添加页面**到侧栏。
- 它可以**读取**一小部分设置和你的主题颜色。
- 它**不能**修改你的启动器列表或设置——这部分是只读的。
- 但因为插件运行在**应用自身的进程里**，没有任何隔离，理论上它能做应用能做的一切。请把插件当成一个你选择运行的程序，而不是一个被沙箱隔离的网页。

## 出问题了怎么办

**重启后插件没有出现。** 检查它的文件夹是否在数据文件夹的 `plugins` 里，以及里面装的是插件文件而不是一个压缩包。然后确认 **启用插件（实验性）** 和该插件自己的开关都打开了。

**我打开了但没有任何变化。** 重启应用——插件开关只在启动时生效。

**某个插件行为异常，或应用出问题。** 在 **设置 → 插件** 里把该插件关掉，重启，看问题是否消失。如果消失，就是该插件引起的；联系提供它的人。错误详情写在数据文件夹的日志文件里（见[出问题了怎么办](troubleshooting.md)）。

想了解它内部是怎么实现的？见 [插件宿主](../development/plugin-host.md)。
