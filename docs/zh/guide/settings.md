# 设置

AgentWorkbench 的所有选项都在 **设置** 里，它是固定在侧栏最底部的那个图标（也可以用 `Ctrl+,`）。页面左侧是一列分区，右侧显示选中的分区。

你当前运行的应用版本显示在分区列表的最底部。

## 外观

整个应用的主题与字体。

- **主题**——配色方案。内置两套：**深色** 和 **浅色**。选完立即生效。
- **字体**——全局使用的字体。第一项 **跟随主题** 表示跟随主题或系统。

两者都立即生效，无需重启。完整说明（包括如何自制主题）见[外观](appearance.md)。

## 启动器

启动器页面上显示的 agent：在这里增删改，并看到每个是否在运行。

- **添加启动器**——打开新建 agent 的表单。
- 每行的 **编辑**——打开同一个表单，内容已填好。
- 每行的 **删除**——确认后移除该 agent。
- 每行还会显示该 agent 的启动命令和一个运行/停止状态点。

如果 agent 正在运行，删除它并不会停止它；请用它的自己的命令停止。删掉的内置 agent 可以用 **高级** 里的 **恢复默认启动器**（或启动器页面上的 **恢复默认**）找回。细节以及「修改内置 agent 只在本次运行内有效」这条重要限制，见 [Agent 启动器](agent-launcher.md)。

## 环境

显示在本机检测到的 Python 与 Node.js 运行环境。有些 agent 用它们来安装或运行，所以缺了值得留意。

- **Python …** 或 **未找到 Python**。
- **Node.js …** 或 **未找到 Node.js**。
- **重新检测**——再查一次。装好或升级了运行环境之后，或改过系统的命令路径之后，点它。

底部状态栏的徽标显示同样信息。出现红叉表示没找到该运行环境。如果你刚装好，重启 AgentWorkbench，让它看到更新后的系统路径。

## Skills

扫描 `SKILL.md` 文件的文件夹。

- 每个来源都有一个开关可以启用或停用，还有一个 × 可以移除。
- 底部的输入框用来添加你自己的文件夹；点 **添加**。
- **重新扫描**会重新扫描一次。

路径里可以用 `~` 表示主目录，用 `%变量名%` 表示环境变量。添加自定义来源会取代内置列表——相关警告和默认文件夹见 [Skills](skills.md)。

## Web

agent 网页界面的显示方式。

- **显示方式**——**内嵌（应用内）** 在应用内的标签页里打开页面；**外部（系统浏览器）** 在你平时的浏览器里打开。默认是内嵌；只有支持内嵌的构建才会列出这个选项。
- **Chromium 旗标**——给内置浏览器引擎的额外启动参数。这是高级项，一般留空。如果内嵌页面因显卡驱动问题启动不了，在这里填 `--disable-gpu`。参数在**重启后生效**。

如果内嵌视图在你机器上就是不行，或者你更愿意用自己的浏览器，就选 **外部（系统浏览器）**。无论这里选什么，启动器和网页上的 **在浏览器打开** 始终可用。见[内嵌网页界面](web-ui.md)。

## 插件

能给应用添加页面的第三方扩展。**默认关闭**，是实验性的高级功能。

- **启用插件（实验性）**——总开关。
- 每个找到的插件各有自己的开关。
- 插件在启动时加载，所以**修改在重启后生效**。

插件运行在应用进程内，没有任何隔离：插件能做的事，应用本身都能做。只启用你信任的插件。见[插件](plugins.md)。

## 高级

存储位置与重置操作。

- 这里显示启动器配置文件的位置。
- **打开数据文件夹**——打开存放应用全部数据的文件夹。
- **恢复默认启动器**——把启动器列表恢复成出厂状态。它会把你删掉的内置 agent 加回来，并把你对内置 agent 的修改还原；你自己添加的 agent 会保留。这个操作立即生效，请谨慎使用。

## 设置存在哪个文件里

应用的全部设置都在一个纯文本文件 `settings.json` 里，放在你的数据文件夹。**一般不需要手动改它**——设置页面会替你写入。如果你确实手动改了，重启应用后生效。你漏掉的项会自动保留默认值，应用不认识的项会被忽略。

数据文件夹里还放着启动器列表（`agents.json`）、哪些 agent 已完成一次性初始化的记录、你的主题、各 agent 网页界面保存的登录状态，以及日志文件。

## 备份与迁移到另一台电脑

要备份你的配置，或把它搬到新电脑上，**把整个数据文件夹复制过去**即可。里面有：

- 你的启动器列表，
- 你的设置，
- 你的主题，
- 各 agent 网页界面保存的登录状态，
- 日志文件。

把复制出来的文件夹放到新机器上的同一位置（文件夹位置见[用户指南](index.md)），启动应用即可。因为它就是一包文件，复制过去就够了，没有别的东西要装。

想了解它内部是怎么实现的？见 [外壳与导航](../development/shell-and-navigation.md)。
