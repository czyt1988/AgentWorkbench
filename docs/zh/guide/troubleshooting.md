# 出问题了怎么办

本页按你看到的症状来组织。每条给出可能的原因，以及你能做什么。

## agent 起不来，或卡片闪红

- **工具没安装。** 用卡片上的 **安装** 动作，或按该 agent 自己的文档安装。
- **工具装了，但不在系统的命令路径里。** 终端里能跑、应用找不到，通常就是这种情况。重装该工具，或确认它的安装目录在系统路径里，然后重启应用。
- **命令写错了。** 打开该 agent 的 **设置** 表单，把启动命令和 agent 自己的说明对一遍。

要看确切原因，看卡片：边框变红、状态文字位置显示了简短信息，弹窗里有完整信息，卡片的控制台面板还留着命令的输出。这三处都值得读。

## 卡片显示运行中，但页面打不开

应用判断「运行中」的标准是：agent 的 Web 地址有任何响应——哪怕是错误响应也算。所以卡片显示运行中、页面却用不了是有可能的。

- **它还在启动。** 有些 agent 要几十秒网页才就绪。等一会儿再重新加载。
- **那个端口被别的程序占了。** 另一个程序可能抢先占了端口，应用其实在跟它说话。见下面「端口冲突」。
- **地址写错了。** 打开 **设置** 表单，把 Web 地址和启动命令里的端口对一遍。

## 内嵌页面白屏或一直转圈

按顺序试：

1. **在浏览器打开**（网页工具栏或卡片右键菜单里）。如果页面在你的浏览器里正常，问题就在内置浏览器。
2. 在 **设置 → Web** 的浏览器启动参数里填 **`--disable-gpu`**，然后重启应用。这在显卡驱动有问题的机器上常能解决白屏。
3. **改用系统浏览器**：把 **设置 → Web** 的 **显示方式** 设为 **外部（系统浏览器）**。之后 agent 页面一律在你自己的浏览器里打开。
4. 如果以上都不行，可能这个页面对内置浏览器来说实在太新了。应用的部分构建使用较旧的内置浏览器引擎，个别很新的网页没法在里面运行。这不是靠设置能解决的——给那个 agent 用 **在浏览器打开** 即可。

## 停止不了 agent

应用只能停掉**本次会话中由它自己启动的** agent。如果是更早启动的，或从别的终端启动的，它不知道那个进程。

- 用卡片右键菜单里的 **强制停止**。它会找到正在服务该 agent Web 地址的程序并结束它，即使不是本应用启动的。
- 或者用 agent 自己的命令停止（比如关掉它自己的终端窗口）。当你不确定强制停止会打到什么的时候，这是最稳妥的办法。

## 端口冲突

两个 agent，或一个 agent 和另一个程序，可能想用同一个端口。

- 默认的 OpenCode 启动器使用 `4096` 端口。如果 `4096` 已被占用，用 **设置** 表单把 OpenCode 启动命令里的端口和它的 Web 地址**一起**改成一个空闲端口。
- 一般来说，想让某个 agent 换端口，就要把它的 **启动命令** 和 **Web 地址** 一起改，两边用同一个新端口。两者必须一致。

（OpenCode 默认随机选端口，正因如此应用把它固定成一个固定端口——固定端口才能让运行检测和「在浏览器打开」可靠。）

## 重复启动同一个 agent

打开一个已经有标签页的 agent，会把那个标签页切到前面，而不会启动第二份。但如果 agent 是**在别处**启动的（你自己开的终端），应用看不到那个进程，点 **开启** 可能会再起一个实例。

启动前先看看它的卡片是否已经显示 **运行中**。如果是，点 **打开** 就好。

## 界面看不清，或颜色怪

- 在 **设置 → 外观** 里试试另一套内置主题。两套都应该是可读的；对比一下有助于你准确描述问题。
- 如果某个具体控件看不清，记下是哪套主题、哪个控件，并反馈——这很可能是 bug。

## 找不到配置，或想重置某项

- **东西都在哪？** **设置 → 高级 → 打开数据文件夹**。
- **恢复 agent 列表：** **设置 → 高级 → 恢复默认启动器**，或启动器页面上的 **恢复默认**。这会把删掉的内置 agent 加回来、把你对内置 agent 的修改还原；你自己添加的 agent 会保留。
- **删除自定义主题：** 从数据文件夹的 `themes` 子文件夹里删掉它的文件。
- **关闭插件：** 在 **设置 → 插件** 里关掉并重启。

## 日志在哪、怎么用

应用会在数据文件夹的 `log` 子文件夹里写日志。它记录应用做过的事：执行的命令、它们的结果、配置改动、检测到哪些 agent 在运行、以及插件加载情况。文件达到 5 MB 就会轮转，只保留最近三个文件，所以不会无限增长。

日志里**不含**你的登录令牌。

反馈问题时把日志文件一起附上——这通常是找出原因最快的办法。

## 怎么完全重置

如果你想从全新状态开始：

1. 退出 AgentWorkbench。
2. 如果数据文件夹里有以后可能还想要的东西，先**备份**它（比如复制到别处）。
3. 删除数据文件夹。
4. 启动应用。它会用全新的默认值重建这个文件夹。

请注意，这会丢失你的启动器列表、设置，以及各 agent 网页界面保存的登录状态。

## 反馈问题时请提供什么

- **应用版本号。** 显示在设置页底部。
- **你的操作系统。**
- **你做了什么**，一步步写清楚，以及实际发生了什么。
- **数据文件夹里的日志文件。**

想了解它内部是怎么实现的？见[开发文档](../development/index.md)。
