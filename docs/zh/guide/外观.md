# 外观

**外观** 用来更换应用的配色方案和字体。内置两套配色——一深一浅——而且都设计成清晰可读。

## 这是什么

**设置 → 外观** 分区里有两个选项：**主题** 和 **字体**。两者都立即生效，不需要重启应用。

## 什么时候用它

- 在深色和浅色配色之间切换。
- 给整个应用换一种字体。
- 安装你自己的自定义配色。

## 更换主题

打开 **设置 → 外观**，用 **主题** 菜单。里面列出所有可用主题。内置的两个显示为 **深色** 和 **浅色**；把指针悬停在菜单上可以看到它们的完整名称（**Catppuccin Mocha (Dark)** 和 **Catppuccin Latte (Light)**）。

选一个，整个界面立刻改变——侧栏、卡片、Web 标签、对话框，所有地方。

两套内置配色都按可读性设计。如果其中某一处文字或控件看不清，值得反馈一下。

## 更换字体

用下方的 **字体** 菜单。第一项 **跟随主题** 表示「使用主题或系统提供的字体」。它下面是你电脑上已安装的字体列表；选一个就会在整个应用里使用它。

改动会立即生效。

## 自己做一个主题

你可以手工做一个配色方案。这是给喜欢折腾的人准备的——日常使用内置两套就够了。

1. 在你的数据文件夹里找到 `themes` 子文件夹。（从 **设置 → 高级 → 打开数据文件夹** 打开它。）如果没有 `themes`，就新建一个。
2. 把某个内置主题文件复制进去。内置文件名为 `mocha-dark.json`（深色）和 `latte-light.json`（浅色）。
3. 把副本改成你想要的 `id` 作为文件名，例如 `my-theme.json`，然后编辑里面的内容。
4. 保存文件。应用会察觉改动并立即重新加载它。
5. 打开 **设置 → 外观**，在 **主题** 菜单里选中你的主题。

要记住的规则：

- **文件名必须和文件里的 `id` 一致。** 名为 `my-theme.json` 的文件里必须写 `"id": "my-theme"`。不一致的文件会被忽略。
- **颜色写成六位十六进制值**，例如 `#89B4FA`。
- **你没写的项会沿用内置主题的值**，取同一个 `variant`（深色或浅色）的内置主题。
- **不认识的项会被忽略**，所以一处小笔误不会把应用弄坏。

最小的主题文件长这样。字段名属于文件格式的一部分，请保留英文：

```json
{
  "id": "my-theme",
  "name": "My Theme",
  "variant": "dark",
  "colors": {
    "windowBg": "#1e1e2e",
    "sidebarBg": "#181825",
    "accent": "#89b4fa",
    "textPrimary": "#cdd6f4"
  }
}
```

`variant` 取 `dark` 或 `light`，决定你没设置的那些颜色从哪套内置主题里取。其余键名对应界面上的各种颜色。最好的起步办法是复制一个内置文件，只改你在意的颜色。

如果你的自定义主题和某个内置主题用了相同的 `id`，以你的为准。

## 每个 agent 的强调色

用来高亮某张 agent 卡片的颜色是在 agent 自己那边设置的，不在这里——见 [Agent 启动器](Agent启动器.md)。留空时，会从当前主题的调色板自动分配一个颜色。

## 出问题了怎么办

**我的主题没出现在列表里。** 检查文件是否在数据文件夹的 `themes` 子文件夹里、文件名是否以 `.json` 结尾、文件名是否和文件里的 `id` 一致。

**我选了主题但没有任何变化。** 确认你选的是正确的条目。一个没有设置任何颜色的主题会完全沿用某个内置主题，所以看起来可能一模一样。至少加一个不同的颜色。

**界面某处看不清。** 换到另一套内置主题对比一下，并反馈上来——两套内置配色都应该是清晰可读的。

**字体改完没生效。** 先选回 **跟随主题**，再重新选你的字体；并确认该字体确实装在你的系统上。

想了解它内部是怎么实现的？见 [主题引擎](../development/主题引擎.md)。
