# Skills

**Skills** 页面把散落在你电脑各处的「技能说明文件」——也就是 agent 和编辑器读取的 `SKILL.md` 文件——集中到一个可搜索的列表里，并显示每个文件的文件夹位置，方便你再次找到它。

## 这是什么

一个 skill 就是一个包含 `SKILL.md` 文件的文件夹，文件里描述了某个 AI 助手能做什么。不同工具把技能放在不同的位置。本页面扫描这些常见位置并把找到的内容列出来，不改动也不移动任何东西。

## 什么时候用它

- 看看这台电脑上装了哪些 skill。
- 查清楚某个 skill 放在哪里。
- 复制某个 skill 的文件夹路径，粘到别处去用。
- 把自己存放 skill 的文件夹加进列表。

## 它怎么工作

页面扫描 **设置 → Skills** 里列出的文件夹，收集其中每一个 `SKILL.md`，每个 skill 显示一张卡片。扫描在后台进行，期间页面照常可用；页面底部有一行简短文字报告找到了多少个 skill、花了多久。

## 搜索、筛选与排序

- **搜索框**——匹配 skill 的名称或描述。
- **筛选按钮**——**全部**、**Agents**、**Claude**、**Codex**、**插件**、**项目**、**自定义**。按来源筛选：点一下按该来源过滤，再点一下取消。
- **排序菜单**——**排序：名称**、**排序：修改时间** 或 **排序：来源**。
- **重新扫描**——立刻重新扫描一次。

## 看懂一张卡片

每张卡片显示 skill 的名称、表示来源的小徽标、一段简短描述、它的文件夹路径，以及一个复制按钮。

把指针在卡片上悬停一会儿，会打开详情浮层，里面有完整描述、来源、`SKILL.md` 文件的确切位置、最后修改时间、大小，以及文件里声明的其它信息。

## 能做什么

- **点卡片**即可复制它的文件夹路径，会有提示确认。
- **在卡片上点右键**可以：
  - **复制路径**——skill 的文件夹。
  - **复制 SKILL.md 路径**——文件本身。
  - **复制名称**——skill 的名称。
  - **打开所在文件夹**——用文件管理器打开该文件夹。
  - **定位 SKILL.md**——打开文件管理器并选中该文件。
- 用键盘选中卡片后，**回车**复制路径，**Ctrl+Enter** 打开文件夹。

## 选择扫描位置

打开 **设置 → Skills** 来管理扫描。

- 每个已有来源都有一个**开关**可以启用或停用，还有一个 × 可以移除。
- 底部的文本框用来添加你自己的文件夹：输入或粘贴一个路径，点 **添加**，或直接按回车。
- **重新扫描**会重新扫描一次。

路径里可以使用：

- `~` 表示你的主目录，例如 `~/.agents/skills`。
- `%变量名%` 表示环境变量，例如 `%USERPROFILE%/my-skills`。
- `*` 作为路径某一段的通配符。

!!! warning "一旦添加了自己的来源，内置列表就被完全取代"
    只要你还没有添加自己的来源，页面就使用内置的文件夹列表。**你添加第一个自定义来源的那一刻起，这份列表就变成了全部列表**——除非你自己把它们加回来，内置的那些文件夹不会再被扫描。如果你想保留某个内置文件夹，请在移除默认项之前或之后手动把它重新添加一遍。

### 内置的文件夹

在没有自定义来源时，页面会查找这些位置：

| 标签 | 文件夹 |
|---|---|
| Agents | `~/.agents/skills` |
| Claude | `~/.claude/skills` |
| Codex | `~/.codex/skills` |
| ZCode plugins | 编辑器插件的缓存目录 |
| Project (.agents) | 当前项目里的 `.agents/skills` |
| Project (.claude) | 当前项目里的 `.claude/skills` |

### 为什么插件 skill 只出现一次

编辑器会把同一个插件的多个版本并排保留。同一个插件出现多次时，只列出最新的那一个，列表因此不会堆满重复项。

## 小技巧

- skill 数量可能很多，用搜索框比滚动更快。
- 点卡片是把路径拿出去粘贴（粘到 agent 或配置文件里）最快的方式。
- 如果某个明明确存在的 skill 没出现，检查它的文件夹是否在扫描来源里，然后点 **重新扫描**。

## 出问题了怎么办

**一个都找不到。** 打开 **设置 → Skills**，确认至少有一个来源是开启的，且路径正确。如果你加过自定义来源，记得它已经取代了内置列表。

**结果里出现奇怪的条目。** 扫描会在任何地方查找 `SKILL.md`，包括其它工具的缓存目录。把不关心的来源关掉即可。

**扫描很慢。** 特别大或层级特别深的文件夹遍历起来更慢。删掉不需要的来源，或把来源指向更窄的文件夹。（深度上限是一个高级设置项，但通常不需要改它。）
