# Agent 工具

**Agent 工具** 是一张提示词草稿纸。你在一个文本编辑框里从容地写提示词，旁边配一个文件树，写好之后把文字复制到 agent 里即可。**本页面不会发送任何内容。**

## 这是什么

一个左右两栏的工作台：左边是编辑区，右边是你某个项目文件夹的浏览器。按回车只会换行——根本不存在会被误触的发送按钮。

## 什么时候用它

- 提示词比较长，直接敲进 agent 的输入框里怕半成品被发出去的时候。
- 想引用项目里的文件，但手打路径太麻烦的时候。
- 想把一条提示词先放着，边看边改的时候。

## 两个分区

- **左边：编辑区。** 你在这里写，输入时会高亮 Markdown 格式。提示词长了可以滚动——拖右侧的滚动条，或直接用滚轮——输入时光标始终留在视野里。
- **右边：文件树。** 显示你选中的工作区文件夹里的文件。中间有一条可拖动的分隔条——拖动它可以给某一侧更多空间。

两栏上方是工具栏：工作区选择、**添加文件夹…**、文件树刷新按钮，以及最右侧的 **复制** 按钮。

## 写一条提示词

1. 从 **工作区** 菜单里选一个文件夹，或点 **添加文件夹…** 添加一个。
2. 在编辑区里写提示词。按回车只会插入一个换行——不会发送任何东西。
3. 从文件树里把文件带进来：**把文件行拖进编辑区**，或**双击文件行**。这会在光标处插入对该文件的引用，写成 `` `./相对路径` `` 的形式。
4. 写完点 **复制**。提示词进入剪贴板并给出确认提示；把它粘贴到 agent 里即可。

**草稿会自动保存。** 关掉应用再打开，文字还在。

## 格式与编辑

在编辑区里点右键，会出现一个菜单，包含：

- 一排快捷格式按钮：**加粗**、**代码段**（行内代码）和 **要点列表**。
- **撤销** 与 **重做**。
- **剪切**、**复制** 与 **粘贴**。

常用键盘快捷键同样可用（见[用户指南](index.md)）。

## 使用文件树

- **点文件夹**可以展开或收起。有内容的文件夹带一个箭头。
- **双击文件**会把对该文件的引用插入编辑区。
- **把文件行拖进编辑区**会在落点插入引用。
- **在文件行上点右键**，有 **复制相对路径** 或 **复制绝对路径**。
- 文件变化时文件树会自动刷新；工具栏上的刷新按钮可以手动刷新。

## 管理工作区文件夹

- **添加文件夹…** 会打开文件夹选择器，可以选电脑上的任意文件夹。
- **工作区** 菜单列出你的文件夹，最近使用的排在最前。选一个即可切换。
- 该菜单里每一项都有一个 ×，可以把它从列表中移除。
- 应用最多记住二十个文件夹。添加第二十一个时，会挤掉最久没用过的那个。

## 小技巧

- 把你正在工作的文件夹加进来，再随手放几个常用的——切换只要点一下。
- 把文件拖进一句话中间，往往比手写路径更快。
- 在这里写好一段可复用的指令，复制一次，粘到多个 agent 里。

## 出问题了怎么办

**列表里少了一个文件夹。** 文件夹上限是二十个，添加新的时候会挤掉最久没用过的那个。还需要就再加一次。

**文件树是空的。** 确认选中的文件夹仍然存在、而且不是空的。这种情况下页面会显示 **工作区文件夹为空或不可用。** 用刷新按钮，或换一个文件夹。

**文件拖不进编辑区。** 确认你拖的是文件树里的行，而不是别处的文字。从文件树拖进编辑区会插入引用；在编辑区内拖文字则是移动这段文字。

**点复制没反应。** 如果编辑区是空的，应用会提示你没有可复制的内容。
