# 内嵌网页界面

**Agent Web UI** 页面把各个 agent 的网页界面以标签页的形式显示在 AgentWorkbench 里，让你不用离开应用、也不用在浏览器窗口之间来回切换，就能同时照看多个 agent。

## 这是什么

每个标签页承载一个 agent 的网页。这些页面运行在应用内置的浏览器里，每个 agent 使用一份独立的私有浏览数据。

## 什么时候用它

- 不切到浏览器就能使用 agent 的网页界面。
- 同时开着多个 agent 的界面。
- 当某个 agent 的页面提示「未运行」时，需要找到重启它的入口。

## 打开一个视图

- 在 **Agent 启动器** 页面上，点运行中 agent 的卡片或其 **打开** 按钮。
- 在本页的空状态里，从运行中的 agent 列表中选一个，点 **打开**。之后也可以点工具栏上的 **主页** 回到这个空状态。

每个 agent 最多只有一个标签页。打开一个已经有标签页的 agent，会把那个标签页切到前面，而不会新建第二个。

## 操作标签页

顶部那一排是所有已打开的标签。

- **切换标签：** 点标签。也可以用 `Ctrl+Tab` / `Ctrl+Shift+Tab`。
- **关闭标签：** 点它的 ×，按 `Ctrl+W`，中键点标签，或在 **更多操作** 菜单里选 **关闭标签**。
- **重新加载：** 按 `F5`，双击标签，或用工具栏的刷新按钮。页面加载中时，同一个按钮会变成停止加载。
- **复制地址：** **更多操作 → 复制 URL**。
- **缩放：** **更多操作 → 放大 / 缩小 / 重置缩放**，或使用[用户指南](index.md)里列出的快捷键。
- **用你自己的浏览器打开：** 点工具栏上的外链按钮。这个入口任何时候都可用。
- **回到 agent 列表：** 点工具栏上的 **主页**。它不会关闭任何标签。

每个标签显示 agent 的名称、一个小状态点，加载中还有一条进度线。把指针悬停在标签上，会用文字说明它当前的状态。

### 被「释放」的标签

为了控制内存占用，应用同时只保留有限数量的网页。当你打开的标签超过这个上限时，最久没用到的那些会被**释放**：标签变灰，显示 **视图已释放以回收内存** 和 **恢复视图** 按钮。

「释放」不等于关闭。标签还在，站点也没有退出登录，只是把页面卸载掉以回收内存。点 **恢复视图** 即可回来。

### 全屏

如果网页请求进入全屏（比如某个游戏或预览），应用会隐藏自己的标签栏，让页面占满窗口。按 `Esc` 退出全屏，标签栏就回来了。

## 页面上的提示层分别是什么意思

当标签页无法显示页面时，会在标签上盖一层提示，附一句简短说明和一个或多个按钮。

| 看到的提示 | 含义 | 该点什么 |
|---|---|---|
| **正在加载…** 加一个转圈 | 页面还在加载。 | 等着；或点 **取消** 停止。 |
| **该 agent 未运行** | 应用连不上该 agent 的 Web 服务。 | 点 **重新启动 agent** 再启动一次，或点 **重试** 再试一次页面。 |
| **页面崩溃了** | 页面的渲染进程停止了。 | 点 **重新加载** 把它拉回来，或点 **在浏览器打开**。 |
| **页面加载失败** | 地址加载不出来；下面会给出简短原因。 | 点 **重试** 或 **重新加载**，或 **在浏览器打开**。 |
| **视图已释放以回收内存** | 该标签被卸载以节省内存。 | 点 **恢复视图**。 |

## 下载的文件去哪了

从 agent 网页下载的文件会存到你系统通常的下载文件夹。下载开始、完成或中断时都会有一条小提示。

想存到别处，需要编辑设置文件（下载文件夹对应 `web.downloadDir` 这一项）；这是高级改动，一般用不到。设置文件的位置见[设置](设置.md)。

## 登录与登录状态会保留吗

**每个 agent 各自记着自己的登录状态，互相独立。** 你登录了某个 agent 的网页界面后，下次打开应用仍然记得，而且不会影响其它 agent。同一台电脑上运行的两个 agent，绝不会看到彼此的 cookie 或保存的会话。

正因如此，应用从不把同一个浏览器会话共享给多个 agent——这是让它们的登录状态不互相串号的唯一办法。

## 什么时候该用外部浏览器

内置浏览器很方便，但它并不能完全替代你平时的浏览器。以下情况请用 **在浏览器打开**：

- 页面在应用内一直空白或加载不完。
- 页面需要以新窗口弹出内容，或跳转到外部服务。
- agent 的页面在内置浏览器里就是无法正常工作。

外部浏览器不受上面那种登录状态隔离的约束，它自己的标签和窗口照常工作。

## 出问题了怎么办

**页面完全打不开。** 先确认 agent 确实在运行（见启动器页面），再试工具栏的刷新按钮，然后试 **在浏览器打开**。如果外部浏览器能用、内置的不行，那问题出在内置浏览器——见[出问题了怎么办](问题排查.md)。

**页面是一片空白。** 先等几秒；有些界面要过一会儿才出现。如果一直空白，用 **在浏览器打开**。很新的网页可能根本没法在内置浏览器里运行（细节见故障排查页）。

**一直转圈。** 点停止按钮（就是刚才那个刷新按钮），然后重新加载。如果 agent 刚启动，给它几十秒——有些 agent 的网页要等一会儿才就绪。

**提示要登录或要令牌。** 用应用弹出的登录对话框登录，或用你的浏览器打开该页面。如果应用里的页面反复要求登录，该 agent 可能需要做一次性初始化——见 [Agent 启动器](Agent启动器.md)。

想了解它内部是怎么实现的？见 [Web 标签页](../development/Web标签页.md)。
